# Nox

Dynamic Island, moniteur système et maintien éveillé (y compris capot fermé) pour macOS
Apple Silicon — en Rust, AppKit natif via `objc2`.

> En cours de développement. Voir `docs/PARITY.md` pour l'état réel de chaque fonction.

Nox reprend le comportement de [Vorssaint](https://vorssaint.com) sur ce périmètre
(référence épinglée : `docs/REFERENCE.md`). Ce n'est pas Vorssaint et ce n'est pas un
produit officiel ou approuvé par Vorssaint. Licence GPL-3.0-or-later — voir `NOTICE.md`.
